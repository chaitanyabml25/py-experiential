
# Rock Paper Scissors - Phase 3

## Project Description
An interactive Rock Paper Scissors game developed
using HTML, CSS and JavaScript.

## Features
- 25 rounds of gameplay
- Player vs Computer
- Random computer selection
- Automatic score calculation
- Win rate calculation
- Longest winning streak
- Bar chart
- Pie chart
- Game history
- Restart option
- Responsive design

## Technologies Used
1. HTML5
2. CSS3
3. JavaScript
4. Vercel
5. GitHub

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.

## Deployment
The project is deployed using Vercel.

## Conclusion
This project demonstrates the use of
JavaScript functions, conditions, random
selection, DOM manipulation and event handling.
